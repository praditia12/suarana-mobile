# 🎵 Suarana

Suarana adalah aplikasi music streaming sederhana yang dibangun menggunakan Flutter sebagai media pembelajaran untuk mempelajari pengembangan aplikasi mobile modern.

## ✨ Features

* Login Authentication
* Home Screen
* Music Player
* Dark Theme UI
* Responsive Layout
* Riverpod State Management

## 🛠️ Tech Stack

### Framework

* Flutter

### State Management

* Riverpod

---

lib/

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/praditia12/suarana-mobile.git
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```

---

## 📦 Build APK

```bash
flutter build apk
```
